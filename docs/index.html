SunSafe

מד חשיפה לשמש חכם — מעקב UV Index בזמן אמת, המלצות מותאמות אישית, והתראות בטלגרם. מבוסס Gemini API ו-MCP (Model Context Protocol).

מה SunSafe עושה

המערכת עוקבת אחר רמת קרינת ה-UV במיקום שלך בזמן אמת, ומחשבת כמה זמן אפשר לשהות בשמש בבטחה — בהתאם לסוג העור שלך ולשימוש בקרם הגנה. כשה-UV גבוה, הבוט שולח התראה עם המלצה ברורה.

💡

UV בזמן אמת

נתוני UV Index חיים לפי מיקום, דרך Open-Meteo — ללא צורך במפתח API.

🧴

המלצה מותאמת

חישוב זמן חשיפה בטוח לפי סוג עור (סולם Fitzpatrick) ושימוש בקרם הגנה.

🤖

סוכן AI

סוכן מבוסס Gemini עונה על שאלות כמו "מה ה-UV עכשיו בתל אביב?" בזמן אמת.

📲

התראות בטלגרם

בוט טלגרם (gil612Bot) שולח התראות ותשובות לשאילתות בצ'אט.

איך זה עובד

ארכיטקטורה מבוססת MCP: הסוכן קורא לשרת MCP ייעודי שמביא נתוני UV חיים, ומחזיר תשובה עם המלצה תוך שניות.

סטטוס הפרויקט

בפיתוח פעיל.

  • Telegram Bot מחובר ונבדק
  • Agent Loop מול Gemini API + Tool ראשוני
  • MCP Weather Server + Agent Loop דרך MCP Client
  • חיבור Agent → Telegram עם fallback לטקסט רגיל
  • Git עם feature branches ו-PRs מסודרים
  • exposure_score — מדד חשיפה יחיד 0-100+ (UV, זמן, סוג עור, קרם הגנה)
  • מודל נתונים ב-Supabase
  • Dashboard ב-Next.js
  • Deploy לפרודקשן (Cloudflare Workers/Pages)

הרצה מקומית

דרישות: Python 3.12+, חשבון Telegram, מפתח Gemini API חינמי.

git clone https://github.com/gil612/sunsafe.git
cd sunsafe

python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt

# העתיקו .env.example ל-.env ומלאו BOT_TOKEN, CHAT_ID, GEMINI_API_KEY

python mcp_agent_loop.py     # בדיקת Agent Loop מול MCP Server
python send_uv_report.py     # שליחת התראת UV בפועל לטלגרם
